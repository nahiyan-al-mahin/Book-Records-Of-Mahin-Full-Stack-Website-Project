# BookShelf 📚

A full-stack book catalog web application.

## Tech Stack
- PHP
- MySQL
- HTML & CSS

## Features
- Admin & Guest login system
- Browse, Search, Add & Delete books
- 300+ books in Bangla & English
- Live at: bookrecordsofmahin.infinityfreeapp.com

## Setup
1. Clone the repo
2. Copy `database.example.php` to `database.php`
3. Fill in your database credentials
4. Import the SQL tables
5. Run on a PHP server
